# 우리아기 MBTI 검사 👶

월령별(0~12개월 / 13~24개월 / 만 2~4세 / 만 5~7세) 행동 질문 12개로 알아보는 아기 기질 테스트입니다.

## 파일 구성
- `index.html` : 사이트 전체 (질문, 결과, 공유, 이미지 저장)
- `og-image.png` : 메신저 공유 썸네일 (1200×630)

## 깃허브 페이지로 올리기
1. 깃허브에서 새 저장소를 만듭니다. (예: `baby-mbti`, Public)
2. `index.html`, `og-image.png`, `README.md`를 업로드합니다.
3. 저장소 **Settings → Pages** 에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/(root)` 로 저장합니다.
4. 1~2분 뒤 `https://내아이디.github.io/baby-mbti/` 에서 열립니다.

## 참고
- 결과 링크에는 유형·점수·월령·이름이 주소에 담겨 있어서, 받은 사람도 같은 결과 화면을 볼 수 있습니다.
- 썸네일은 모든 결과 링크에서 동일하게 표시됩니다(정적 호스팅 특성).
- 재미로 즐기는 검사이며, 기질 연구(활동성·접근성·적응성·규칙성 등)를 참고해 MBTI 틀에 맞춘 것입니다.
